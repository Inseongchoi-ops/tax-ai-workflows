# Payroll Compliance Workflow

## Monthly Review
- Review payroll reports
- Verify withholding accounts
- Confirm state registrations
- Review employee classifications

## Quarterly Tasks
- File Form 941
- Reconcile payroll tax payments
- Review state withholding filings

## Year-End Tasks
- Prepare W-2 forms
- Review contractor payments
- File 1099 forms
- Archive payroll records
